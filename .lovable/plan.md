# HOME corporativa de Automatizza

## Objetivo
Construir únicamente la página principal de Automatizza como una evolución comercial y corporativa del lenguaje visual aportado: editorial, técnico, limpio y con una jerarquía tipográfica muy marcada.

## Propuesta
- Crear un encabezado ligero y discreto con el logo oficial, navegación preparada para futuras páginas y botón “Hablemos”.
- Diseñar un hero de alto impacto con el mensaje principal, dos llamadas a la acción y una composición propia inspirada en interfaces empresariales reales, sin recurrir a imágenes de stock ni al típico collage SaaS.
- Construir las secciones de problema, soluciones, proyectos, forma de trabajar, calculadora, presentación de Automatizza, cierre comercial y pie de página siguiendo exactamente el contenido indicado.
- Dar mayor protagonismo visual a Silos Spain que a APC y dejar claro que Silos Spain continúa evolucionando.
- Presentar la calculadora como una herramienta creíble con controles y resultado de muestra, enlazando a `/calculadora` sin desarrollar todavía esa página.
- Preparar los enlaces de navegación sin crear páginas interiores; los enlaces a secciones disponibles llevarán al contenido correspondiente de la HOME y los futuros destinos quedarán claramente estructurados para ampliarse después.

## Dirección visual
- Usar exclusivamente la identidad indicada: azul marino `#02135F`, cian `#02A0FC`, blanco, gris claro y grises corporativos.
- Usar Space Grotesk para titulares e Inter para texto.
- Mantener mucho espacio en blanco, líneas finas, numeración discreta, bloques tipográficos amplios y composiciones asimétricas.
- Alternar zonas editoriales, diagramas, cifras e interfaces sobrias para evitar una sucesión de tarjetas genéricas.
- Aplicar animaciones muy contenidas, con respeto por la preferencia de movimiento reducido.
- Diseñar expresamente las adaptaciones para escritorio, tableta y móvil, incluyendo una navegación móvil compacta.

## Recursos y estructura
- Incorporar el PNG oficial del logo mediante el sistema de recursos del proyecto y crear a partir de él un favicon cuadrado, sin alterar ni reconstruir la marca.
- Mantener las capturas únicamente como referencia; no se incluirán en la web.
- Separar la HOME en componentes reutilizables y pequeños conjuntos de datos para facilitar su continuación posterior.
- No conectar servicios externos, almacenamiento, formularios, APIs, reservas ni bases de datos.

## SEO y accesibilidad
- Configurar el título y la descripción proporcionados, además de etiquetas sociales coherentes para la HOME.
- Usar un único H1, estructura semántica, navegación accesible, foco visible, textos alternativos y contraste adecuado.
- Mantener el contacto como enlace de correo y no como formulario.

## Validación
- Comprobar que la página se renderiza sin errores.
- Revisar visualmente escritorio y móvil para detectar recortes, solapamientos, desbordamientos o problemas de jerarquía.
- Verificar navegación, botones, enlaces internos, menú móvil y respeto por movimiento reducido.
